# Documentation artwork

`simulation-branches.png` is a conceptual illustration generated with the built-in image-generation tool. It is not a screenshot of the sample platformer.

Prompt:

Use case: stylized-concept. Asset type: wide documentation cover illustration for Bevy Agent, a Rust library for controlled game simulations. Primary request: a beautifully crafted isometric miniature platformer simulation on a pale cool ivory background. Three successive floating diorama tiles form a left-to-right sequence showing the same small geometric amber player moving across indigo platforms toward a teal collectible, with a subtle branching path from the middle state to an alternative final tile. Visual metaphor for step, snapshot, replay and branching. Style: precise editorial technical illustration with tactile matte clay geometry, subtle grid, thin indigo connector lines and generous negative space, sophisticated developer-tool documentation aesthetic. Colors match the website: ink navy #18233b, indigo #4158c5, muted teal, warm amber accents, very light #fafbfe background. Composition: panoramic 3:1 landscape, all geometry comfortably inside frame, clear at small sizes, polished soft shadows. No text, no lettering, no logos, no watermarks, no UI screenshot, no photoreal humans. This is a conceptual illustration, not a real game screenshot.

`control-loop.svg` and `snapshot-replay.svg` are editable technical diagrams authored from the runtime contracts. Their labels and arrows should be reviewed alongside changes to the corresponding guides.
